# ResourceSystem 人工测试场景

打开本目录的 `ResourceSystemTest.unity`，点击 Unity 编辑器顶部的播放按钮，然后手动操作 Game 窗口中的按钮。它是普通场景，无需通过 Test Runner 启动。

建议 Game 窗口使用 1280 × 960 或放大查看。界面会按窗口尺寸缩放，中文字体优先使用运行机的 Microsoft YaHei、SimHei 或 Noto Sans CJK SC。

## 场景内容

- **纹理 / 精灵**：输入地址，分别通过 `LoadAsync<Texture2D>`、`LoadAsync<Sprite>` 加载到预览区域。可再次加载以替换当前图片；失败或取消保留原图。
- **GameObject**：输入 Prefab 地址和加载数量，通过 `RentAsync<GameObject>` 追加租用实例。输入回收数量后，后加载的先回收；超过在用数时实际回收全部。
- **取消加载**：加载中点击顶部“取消当前加载”。仅取消当前请求或批次；批次中已交付的实例保留，后续可以继续加载、回收。
- **缓存与日志**：显示资源引用、在用 / 闲置实例、资源与实例残留，以及卸载和清池结果。实例预览、缓存和日志区域均可滚动。

三类预览资源均通过地址加载。场景引用专用的 `ResourceSystemManualConfig.asset` 创建独立资源系统；配置启用了 Resources 加载器的 `UnloadAssetOnRelease` 和 `GameObjectFactoryConfig`，每种原型最多保留 32 个闲置实例。

## 指定资源与数量

在 Game 窗口中编辑地址输入框，填写任意 `Resources` 目录下的相对路径，不包含 `Resources/` 前缀和文件扩展名。例如 `Assets/MyAssets/Resources/UI/Icon.png` 对应 `UI/Icon`。精灵图片需导入为 Sprite，当前示例使用 Single 模式。编辑器未播放时，也可选中对应 InputField 修改默认文本。

加载数量和回收数量必须是大于 0 的整数；空值、负数、0 和超出整数范围的输入会提示失败，并保留当前内容。每次点击会固定本次的地址和数量，操作结束后才能编辑下一次输入。

示例 Prefab 是 UI 机器人，实例区使用 UI 网格展示。普通非 UI GameObject 也可按地址租用和回收，在 Hierarchy / Scene 窗口观察；该预览区域未配置 3D 摄像机。

批量加载逐帧推进，便于人工取消。小图片或缓存命中可能瞬间完成，完成后取消按钮会禁用。取消代表结束资源系统的本次等待，不保证中止 Unity 已发起的底层 Resources 请求；迟到结果不会覆盖当前预览。

## 建议人工操作顺序

| 操作 | 预期结果 |
| --- | --- |
| 播放场景，等待初始化完成 | 缓存条目为 0，三个加载按钮可点击 |
| 分别点击加载纹理、加载精灵；加载数量填 3，再加载 GameObject | 三个区域都有内容；缓存条目为 3，实例在用 3、闲置 0；每项资源持有数为 1（实例池按原型聚合持有） |
| 回收数量填 1，再点击按数量回收 | 实例在用 2、闲置 1；回收对象停用，仍由实例池持有 |
| 加载数量填 1，再加载 GameObject | 在用恢复为 3、闲置为 0，复用刚回收的实例 |
| 点击“仅卸载空闲缓存” | 已卸载 0、在用跳过 3；预览和实例保持可见 |
| 点击“归还纹理引用” | 纹理预览消失；缓存仍有 3 项，纹理持有数变为 0 |
| 再点击“仅卸载空闲缓存” | 已卸载 1、在用跳过 2；缓存剩 2 项 |
| 回收数量填 99，再点击按数量回收 | 实际回收剩下的 3 个，在用 0、闲置 3；原型引用仍由池持有 |
| 点击“清空实例池” | 销毁闲置实例；原型持有数变为 0，可以卸载 |
| 点击“释放全部并卸载缓存” | 预览清空、实例销毁、缓存条目和残留均为 0 |
| 点击“Unity 清理未使用资产” | 执行一次 Unity 全局空闲资产扫描，日志显示完成 |
| 再次加载三类资源 | 图片、精灵和实例均可重新出现 |

取消检查：加载数量填 100，开始后点击取消，观察已完成数量停止增长；再加载 2 个，应在保留数量上增加 2。也可更换图片地址后取消，再输入另一地址加载，检查旧请求不会覆盖新图片。

清池检查：有在用实例时点击清池，不会强制销毁在用实例，但该桶已关闭；这些实例随后回收时直接销毁。再次加载会进入新的池桶。

## 卸载边界

归还 `ResourceRef` 只减少持有数；`UnloadAsync` 才会移除可卸载的缓存记录并执行释放。在用资源会被跳过，释放失败的资源保留为残留供后续重试。

回收实例归还的是 `InstanceLease`；只要池中仍有闲置或在用对象，池就持有原型。“清空实例池”关闭池桶；“释放全部并卸载缓存”依次归还全部实例、清池、卸载资源。

纹理和精灵会按配置调用 `Resources.UnloadAsset`。这两个示例使用独立 PNG；自选资源若共享同一底层纹理，需要同时考虑 Unity 的共享资产引用。Unity 不支持以该接口卸载 GameObject Prefab，因此日志中 Prefab 的“已卸载”表示资源系统缓存记录已移除。归还全部实例后，可使用“Unity 清理未使用资产”，先清池与缓存，再让引擎回收全局未被引用的资产；场景或静态字段仍引用的资产会保留。

控制器销毁时会发起清理：取消在途请求、清理预览和实例、归还引用，再关闭本场景拥有的资源系统。Unity 停止播放不会等待异步清理完成；人工检查释放结果时，请先点击“释放全部并卸载缓存”，确认缓存和残留均为 0，再停止播放。

## 维护

操作逻辑位于 `ResourceSystemManualTest.cs`。选中场景中的 `ResourceSystem Manual UI` 可查看专用配置和界面绑定。示例资源位于 `Resources/ResourceSystemManual`；替换图片或 Prefab 后，确保地址输入框中的路径对应正确。

场景脚本使用父目录的 `ManualModeTests` 运行时程序集，本目录没有自动测试用例。临时验证脚本仅保存在工作区 Temp。
